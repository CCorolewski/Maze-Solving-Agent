This was an interesting build. At first I really liked the challenge of creating an AI agent to solve mazes, but then I started to implement the agent and was permanently frustrated. I'd heard AI were bad at spacial challenges and I now see why. When I started my agent it seemed as if it would decide if it would follow my prompt or not. I specifically stated to move only in a step size of 1 unit, but it would frequently start by taking the biggest moves it could and thus missing many possible branches. After restarting the agent multiple times I would get an instance where it would obey my prompt. When this was the case it worked well, however I tried changing my prompt text/format/conditions multiple times and still recieved random results from the agent. My only solution was to restart the agent until it behaved according to my prompt. Another issue I ran into was how slow Ollama Cloud can be, it really limited my abilitiy to solve all the mazes. It was a frequent problem where it would freeze for 5+ minutes and I wouldn't be sure if I should restart or wait it out, after 10 minutes of inactivity I would restart. On an interesting note that also frustrated me, I specifically told it to store its movement data in a stack and avoid getting stuck in loops; as I write this on maze 4 has been stuck in a loop for the last 45 minutes. My agent has taken both directions of the loop and has yet to step outside. It was able to solve mazes 1-3 but we will see if it can solve maze 4 before midnight.
